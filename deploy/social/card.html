Every RAG tutorial adds a cross-encoder reranker. I added one too — then hand-labelled 1,237 relevance judgements to check whether it actually helped.

ConfigurationnDCG@10p50
BM25 only0.57534 ms
Dense only0.6581 ms
Hybrid (RRF)0.70132 ms
+ cross-encoder0.7171,802 ms
+0.016 nDCG for 56× the latency
95% CI [−0.028, +0.061] — spans zero. Not a real gain.
So I kept it — for a completely different reason.
Fusion scores come from rank position — meaningless in absolute terms. The reranker is the only calibrated signal, and the only reason the system can say “I don’t know.”
